# Historical result provenance

These files are sanitized exports of the original 2022 evaluation outputs.
Absolute local paths and CSV index columns were removed; numeric values were not
changed. `summary.json` is generated as the arithmetic mean of each metric over
518 per-image rows.

The source run used a deterministic holdout created from the available ISIC
2018 training pairs. Because the original input snapshot and checkpoints are
not distributed, treat these records as archived evidence rather than a fully
reproducible contemporary benchmark.
